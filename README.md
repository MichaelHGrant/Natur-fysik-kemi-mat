# Fysik, matematik og kemi

Interaktive demonstrationer og simulationer i fysik, matematik, kemi og astronomi – fra atomets indre til kometbaner, med egne astrofotos og målinger fra Djursland.

**Siden:** <https://michaelhgrant.github.io/Natur-fysik-kemi-mat/>

Alt er skrevet på dansk og henvender sig til gymnasieelever, lærere og alle andre med lyst til at se fysikken i bevægelse. Simulationerne løser bevægelsesligningerne direkte i browseren, så man kan skrue på parametrene og se, hvad der sker.

## Nyeste sider

- **[Koblede penduler](koblede-penduler.html)** – en 3D-simulation, hvor pendulerne kobles med fjedre eller hænger på en udspændt snor, og hvor du selv tilføjer og fjerner op til otte penduler, giver dem hver sin masse og længde og trækker kuglerne ud med musen. Siden beregner normalsvingningerne og deres perioder, måler hvert penduls periode og viser energien vandre. Teori: svævning, afstemning og resonans, energioverførsel som ved et elastisk stød, og kæden som bølgeleder. Med en [vejledning i at bygge forsøget selv](koblede-penduler.html#byg-selv) af snor og møtrikker.
- **[Gyroskopet og tippetoppen](gyroskop-tippetop.html)** – nu udvidet med [inertinavigation](gyroskop-tippetop.html#inertinavigation): kardanplatform og kardanlås, strapdown, ringlaserens Sagnac-effekt, MEMS-gyroskoper og Schuler-pendulet med perioden 84,4 minutter, med en interaktiv graf over, hvordan sensorfejl bliver til positionsfejl.

## Teknik

Siden er ren statisk HTML, CSS og JavaScript uden byggetrin og hostes på GitHub Pages direkte fra `main`.

- **3D:** [Three.js r128](https://threejs.org/) fra cdnjs
- **Formler:** [MathJax 3](https://www.mathjax.org/) fra jsDelivr
- **Grafer:** tegnet direkte på `<canvas>`
- **Design:** fælles mørkt tema (`--space-black`, `--aurora-green`, `--aurora-blue`, `--gold`), som hver side har i sin egen `<style>`-blok

Hver side er selvstændig, så en side kan kopieres, rettes og lægges op for sig.

### Kør siden lokalt

De fleste sider kan åbnes direkte i browseren. Nogle testsider indlæser spørgsmål fra separate filer og kræver en lille webserver:

```bash
python3 -m http.server 8000
```

Åbn derefter <http://localhost:8000/>.

### Tilføj en ny side

1. Kopiér en eksisterende side med samme type indhold, fx `koblede-penduler.html` for en 3D-simulation, og behold `<style>`-blokken.
2. Ret `<title>`, `<meta name="description">` og `<link rel="canonical">`.
3. Tilføj et kort (`<article class="content-card">`) under det rette afsnit i `index.html`, med dybe links til sidens afsnit.
4. Tilføj siden i denne README.
