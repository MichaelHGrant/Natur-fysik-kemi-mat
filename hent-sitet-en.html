Using the copy

  1. Unzip the file. It gives the folder Natur-fysik-kemi-mat-main.
  2. Open index.html in a browser – that gives you the Danish home page with links to every page. English home page: index-en.html.
  3. To use individual pages, copy them to a folder of their own. Many pages are self-contained; others load images, scripts and shared files from the same folder, so take those too.

On the school web server or intranet: Put the whole folder on the server as it is. Everything is ordinary static files (HTML, JavaScript, images), so no database or installation is needed.

On a single computer: A few pages, the site map among them, load data from other files and only work when served by a web server. If the computer has Python, you can start a small local server in the folder and open http://localhost:8000:

cd Natur-fysik-kemi-mat-main
python -m http.server 8000

On a learning platform (such as Moodle, Teams or Google Classroom): It is often easiest to link directly to the pages on mhgfysik.dk or to upload the PDF editions that exist for many of the pages.

Internet and limitations

  • Many pages load shared libraries from the web – MathJax for formulas, three.js for the 3D models and some fonts – so a local copy still needs an internet connection to show formulas and 3D correctly.
  • The local copy does not update itself. Download the zip file again when you want the latest pages.
  • The self-marking tests do not store students’ answers anywhere; they are marked in the student’s own browser.

With full history

The whole site is openly available on GitHub. With Git you can fetch it with every earlier version and later update your copy with git pull:
